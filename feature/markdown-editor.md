# Markdown 编辑器功能需求（类 Typora）

## 运行上下文

- **所在页面**：Options 页面（完整浏览器标签页，空间充足）
- **数据存储**：`chrome.storage.local`，本地持久化
- **技术选型**：Milkdown（基于 ProseMirror，插件化架构，Vue 支持好）

---

## 最终功能清单

### 一、核心编辑体验

| # | 功能 | 说明 |
|---|------|------|
| 1 | **所见即所得 (WYSIWYG)** | 输入 Markdown 语法后立即渲染为最终效果，不分编辑区/预览区 |
| 2 | **源码模式切换** | 可切换到纯 Markdown 源码模式查看/编辑 |
| 3 | **实时语法解析** | 输入 `#`、`-`、`>` 等符号后自动识别并渲染 |
| 4 | **光标定位即编辑** | 点击已渲染的内容可回到 Markdown 源码进行编辑 |

### 二、Markdown 元素支持

| # | 功能 | 说明 |
|---|------|------|
| 5 | **标题** (H1-H6) | `# ~ ######` |
| 6 | **段落与换行** | 空行分段，`Shift+Enter` 软换行 |
| 7 | **加粗/斜体/删除线** | `**bold**` / `*italic*` / `~~del~~` |
| 8 | **有序/无序列表** | `1.` / `-` / `*`，支持嵌套缩进 |
| 9 | **任务列表** | `- [ ]` / `- [x]`，可点击勾选 |
| 10 | **引用块** | `>` blockquote，支持嵌套 |
| 11 | **代码块** | 围栏代码块，支持语言高亮 |
| 12 | **行内代码** | 行内代码片段 |
| 13 | **分割线** | `---` / `***` |
| 14 | **链接** | `[text](url)` |
| 15 | **图片** | `![alt](url)`，显示图片预览 |
| 16 | **表格** | `| col |` 语法，可视化编辑表格行列 |

### 三、编辑器功能

| # | 功能 | 说明 |
|---|------|------|
| 17 | **撤销/重做** | Ctrl+Z / Ctrl+Shift+Z |
| 18 | **快捷键** | 加粗 Ctrl+B、标题 Ctrl+1~6、保存 Ctrl+S 等 |
| 19 | **工具栏** | 顶部格式化工具栏按钮 |
| 20 | **自动补全** | 括号、引号等自动配对 |
| 21 | **智能缩进** | 列表回车自动缩进延续 |
| 22 | **字数统计** | 实时显示字符数/字数 |

### 四、笔记管理

| # | 功能 | 说明 |
|---|------|------|
| 23 | **多笔记列表** | 侧边栏展示笔记列表，支持创建/切换/删除 |
| 24 | **笔记标题** | 自动取首行标题或支持手动命名 |
| 25 | **自动保存** | 编辑内容实时自动保存到 `chrome.storage.local` |
| 26 | **笔记排序** | 按修改时间倒序排列 |
| 27 | **删除确认** | 删除笔记时弹出二次确认，防止误删 |

### 五、本地文件操作

| # | 功能 | 说明 |
|---|------|------|
| 28 | **打开本地 .md 文件** | 通过 File System Access API 的 `showOpenFilePicker()` 打开本地 Markdown 文件 |
| 29 | **保存回原文件 (Ctrl+S)** | 通过 `FileHandle.createWritable()` 将编辑内容直接写回原文件路径 |
| 30 | **另存为** | 通过 `showSaveFilePicker()` 将内容保存到用户指定位置 |

> **技术说明**：File System Access API 仅 Chromium 内核浏览器支持（Chrome / Edge），Firefox 不支持。每次打开浏览器后需用户重新授权文件访问。本地文件与插件内笔记独立管理，打开的本地文件在编辑器顶部标注文件路径来源。

### 六、导出与复制

| # | 功能 | 说明 |
|---|------|------|
| 31 | **复制为 Markdown** | 一键复制编辑内容为原始 Markdown 文本 |
| 32 | **复制为 HTML** | 一键复制渲染后的 HTML |
| 33 | **导出为 HTML 文件** | 下载为 `.html` 文件 |
| 34 | **导出为 Markdown 文件** | 下载为 `.md` 文件 |

### 七、外观

| # | 功能 | 说明 |
|---|------|------|
| 35 | **大纲面板** | 右侧显示文档标题大纲，可点击跳转 |

## 排除功能

| 功能 | 排除原因 |
|------|----------|
| 查找/替换 | 实现复杂度高，后续迭代 |
| 脚注 | 偏重度写作，场景少 |
| 数学公式 | 需引入 KaTeX/MathJax，体积大 |
| Mermaid 图表 | 需引入 Mermaid 库，体积大 |
| HTML 内嵌 | 安全风险高 |
| 目录 (TOC) | 大纲面板已替代 |
| YAML Front Matter | 偏技术写作，场景少 |
| 拖拽排序 | 实现复杂，优先级低 |
| 导出 PDF/Word | 插件里实现复杂 |
| 图片管理/图床 | 插件里实现困难 |
| 主题切换 | 优先级低，后续可迭代 |
| 专注模式 | 优先级低，后续可迭代 |
| 打字机模式 | 优先级低，后续可迭代 |
| 右键菜单 | 优先级低，工具栏已覆盖 |
