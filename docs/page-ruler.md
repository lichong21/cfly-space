# 页面标尺/测量工具 — 功能需求文档

## 运行上下文

- **所在页面**：通过 Content Script 注入到当前浏览页面
- **触发方式**：Popup 面板点击触发 / 快捷键触发
- **数据存储**：无需持久化
- **权限需求**：需要 `activeTab` + `scripting` 权限（已有 `scripting` 和 `tabs`）
- **优先级**：P3（需要 Content Script 注入，复杂度高）

---

## 一、核心目标

提供页面元素的像素级测量功能，帮助前端开发者测量元素尺寸、间距、边距，辅助设计稿还原和页面调试。

---

## 二、功能清单

### 1. 元素信息查看

| # | 功能 | 说明 |
|---|------|------|
| 1 | **元素高亮** | 鼠标悬停在页面元素上时，高亮显示元素边界（蓝色边框） |
| 2 | **尺寸标注** | 在元素旁显示宽度 × 高度（px） |
| 3 | **盒模型信息** | 显示选中元素的 margin、border、padding、content 尺寸 |
| 4 | **位置信息** | 显示元素的 top、left 偏移量 |
| 5 | **CSS 属性** | 显示关键 CSS 属性（font-size、color、background-color 等） |

### 2. 距离测量

| # | 功能 | 说明 |
|---|------|------|
| 6 | **元素间距测量** | 点击选中一个元素后，悬停其他元素时显示两元素之间的距离 |
| 7 | **距离标注线** | 用虚线标注两元素间的水平和垂直距离 |

### 3. 标尺与参考线

| # | 功能 | 说明 |
|---|------|------|
| 8 | **像素标尺** | 页面顶部和左侧显示像素刻度尺 |
| 9 | **参考线** | 从标尺拖出水平/垂直参考线，辅助对齐 |
| 10 | **参考线吸附** | 参考线自动吸附到元素边界 |

### 4. 区域测量

| # | 功能 | 说明 |
|---|------|------|
| 11 | **矩形选区** | 拖拽绘制矩形选区，显示选区的宽 × 高 |
| 12 | **选区颜色** | 半透明蓝色填充，边缘标注尺寸 |

### 5. 工具控制

| # | 功能 | 说明 |
|---|------|------|
| 13 | **开启/关闭** | 通过 Popup 按钮或快捷键一键开启/关闭测量模式 |
| 14 | **模式切换** | 切换测量模式：元素信息 / 距离测量 / 区域测量 |
| 15 | **颜色取色** | 与颜色工具联动，悬停时显示元素的颜色信息 |

## 三、交互设计

### 激活方式

1. 打开 Popup 面板 → 点击「页面标尺」按钮 → 注入 Content Script → 进入测量模式
2. 快捷键 `Alt+Shift+R`（可配置）直接激活

### 测量模式 UI

- 页面顶部出现一个浮动工具条：
  - 模式选择（元素信息 / 距离测量 / 区域测量）
  - 关闭按钮
- 鼠标样式变为十字光标
- ESC 键退出测量模式

### 信息面板

- 固定在页面右下角的浮动面板
- 实时显示当前悬停元素的详细信息
- 可拖拽移动位置
- 可折叠/展开

---

## 四、技术要点

### Content Script 注入

- 使用 `chrome.scripting.executeScript` 动态注入
- 注入独立的 CSS 和 JS，使用 Shadow DOM 隔离样式
- 所有注入元素使用高 z-index 确保覆盖页面内容

### 性能考量

- 使用 `getBoundingClientRect()` 获取元素尺寸
- 使用 `getComputedStyle()` 获取 CSS 属性
- 鼠标移动事件使用 `requestAnimationFrame` 节流
- 测量覆盖层使用绝对定位，不影响页面布局

---

## 五、典型使用场景

1. **设计还原**：对照设计稿测量页面元素的尺寸和间距是否准确
2. **像素对齐**：检查元素之间的对齐和间距是否一致
3. **调试布局**：查看元素的盒模型信息，排查布局异常
4. **样式提取**：快速获取元素的关键 CSS 属性值

## 六、排除功能

| 功能 | 排除原因 |
|------|----------|
| 截图标注 | 需要 Canvas 截图能力，独立功能 |
| 设计稿叠加对比 | 实现复杂度极高 |
| CSS 修改 | 超出测量工具范围，浏览器 DevTools 已提供 |
| 响应式测试 | 浏览器 DevTools 已提供 |
