# 剪贴板历史 — 功能需求文档

## 运行上下文

- **所在页面**：Popup 弹出面板 + Options 页面（完整管理）
- **数据存储**：`chrome.storage.local`，本地持久化
- **权限需求**：可能需要 `clipboardRead` 权限（需评估）
- **优先级**：P3（需要 Content Script，实现复杂度较高）

---

## 一、核心目标

记录用户在浏览器中的复制操作历史，提供快速搜索和再次复制功能，解决程序员在多文件间频繁复制代码片段时丢失剪贴板内容的痛点。

---

## 二、功能清单

### 1. 历史记录

| # | 功能 | 说明 |
|---|------|------|
| 1 | **自动记录** | 用户在浏览器页面中执行复制操作时，自动记录复制内容 |
| 2 | **去重** | 连续复制相同内容不重复记录，将已有记录置顶 |
| 3 | **条数限制** | 最多保留最近 100 条记录，超出自动淘汰最旧记录 |
| 4 | **时间标记** | 每条记录显示复制时间（相对时间，如「5 分钟前」） |
| 5 | **来源标记** | 记录复制时所在页面的标题和 URL |

### 2. 搜索与筛选

| # | 功能 | 说明 |
|---|------|------|
| 6 | **关键词搜索** | 输入关键词实时过滤历史记录 |
| 7 | **内容预览** | 长文本截断显示，鼠标悬停显示完整内容 |
| 8 | **分类标签** | 自动识别内容类型标签（代码、URL、纯文本、数字） |

### 3. 操作功能

| # | 功能 | 说明 |
|---|------|------|
| 9 | **一键复制** | 点击记录即可重新复制到剪贴板 |
| 10 | **删除单条** | 支持删除指定记录 |
| 11 | **清空全部** | 一键清空所有历史记录 |
| 12 | **收藏/置顶** | 重要内容可收藏置顶，不被自动淘汰 |

### 4. Popup 快捷面板

| # | 功能 | 说明 |
|---|------|------|
| 13 | **最近 5 条** | Popup 面板中展示最近 5 条剪贴板记录 |
| 14 | **快速复制** | 点击即可复制，无需打开 Options 页面 |
| 15 | **跳转管理** | 底部「查看全部」链接跳转到 Options 页完整管理 |

## 三、交互设计

### Popup 布局

- 在现有 Popup 工具列表下方增加「最近复制」区域
- 展示最近 5 条记录（截断显示），点击即复制

### Options 布局

- 顶部：搜索框 + 清空按钮
- 主体：记录列表（卡片式），每条显示：
  - 内容预览（前 200 字符）
  - 时间标记 + 来源标记 + 类型标签
  - 操作按钮（复制 / 收藏 / 删除）
- 收藏的记录置顶显示，与普通记录视觉区分

## 四、技术实现方式

剪贴板历史的核心难点在于**如何捕获复制操作**：

### 方案：Content Script 监听（推荐）

- 通过 Content Script 注入到页面，监听 `document` 的 `copy` 事件
- 获取 `window.getSelection()` 或 `event.clipboardData` 中的复制内容
- 通过 `chrome.runtime.sendMessage` 发送到 Background 存储

### 权限需求

- 需要 `activeTab` 或 host permissions 来注入 Content Script
- 需要评估权限最小化原则

---

## 五、典型使用场景

1. **多文件开发**：在不同文件间复制代码片段，回溯之前复制的内容
2. **信息收集**：浏览多个网页时复制关键信息，统一查看
3. **重复粘贴**：需要反复使用某段代码或文本时，从历史中快速取用

---

## 六、排除功能

| 功能 | 排除原因 |
|------|----------|
| 图片剪贴板 | 存储空间大，实现复杂 |
| 跨浏览器同步 | 需要服务端，与本地化原则冲突 |
| 快捷键粘贴 | 需要复杂的 Content Script 注入和 UI 覆盖 |
| 富文本保存 | 增加存储复杂度，纯文本已满足需求 |
