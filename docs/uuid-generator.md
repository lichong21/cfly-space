# UUID / 随机数据生成器 — 功能需求文档

## 运行上下文

- **所在页面**：Options 页面（完整浏览器标签页）
- **数据存储**：无需持久化（纯工具型，无状态）
- **优先级**：P1（实现简单，开发测试中常用）

---

## 一、核心目标

提供常见唯一标识符和随机测试数据的一键生成功能，替代反复访问在线工具的低效操作，提升开发和测试效率。

---

## 二、功能清单

### 1. UUID 生成

| # | 功能 | 说明 |
|---|------|------|
| 1 | **UUID v4** | 生成标准 RFC 4122 UUID v4（随机生成） |
| 2 | **批量生成** | 支持一次生成 1 ~ 50 个 UUID |
| 3 | **格式选项** | 标准格式（带连字符）/ 无连字符 / 大写 / 小写 |
| 4 | **一键复制** | 复制单个或全部生成结果 |

### 2. 随机字符串

| # | 功能 | 说明 |
|---|------|------|
| 5 | **自定义长度** | 指定生成长度（默认 16，范围 1 ~ 256） |
| 6 | **字符集选择** | 可勾选：大写字母 / 小写字母 / 数字 / 特殊字符 |
| 7 | **批量生成** | 支持一次生成多个随机字符串 |
| 8 | **密码强度提示** | 根据字符集和长度评估密码强度等级 |

### 3. 随机数字

| # | 功能 | 说明 |
|---|------|------|
| 9 | **随机整数** | 指定范围（min ~ max）生成随机整数 |
| 10 | **随机浮点数** | 指定范围和小数位数生成随机浮点数 |
| 11 | **批量生成** | 支持一次生成多个随机数 |

### 4. Mock 数据生成

| # | 功能 | 说明 |
|---|------|------|
| 12 | **姓名** | 随机生成中文姓名（常见姓 + 常见名） |
| 13 | **手机号** | 随机生成符合格式的 11 位中国手机号 |
| 14 | **邮箱地址** | 随机生成邮箱地址（随机用户名 + 常见域名） |
| 15 | **身份证号** | 随机生成符合校验规则的身份证号（测试用） |
| 16 | **IP 地址** | 随机生成 IPv4 地址 |
| 17 | **日期时间** | 指定范围内的随机日期时间 |

### 5. 通用交互

| # | 功能 | 说明 |
|---|------|------|
| 18 | **一键复制** | 每个生成结果旁提供复制按钮 |
| 19 | **批量复制** | 将所有生成结果以换行分隔复制 |
| 20 | **重新生成** | 保持当前配置不变，一键重新生成 |

---

## 三、交互设计

### 布局

- 顶部：功能类型切换 Tab（UUID / 随机字符串 / 随机数字 / Mock 数据）
- 左侧：配置面板（各类型对应的参数设置）
- 右侧：生成结果区域（列表展示，每项带复制按钮）
- 底部：「重新生成」「复制全部」操作按钮

### UUID Tab

- 格式选项（单选）：标准 / 无连字符 / 大写
- 生成数量：数字输入框或滑块（1 ~ 50）
- 生成按钮
- 结果列表

### Mock 数据 Tab

- 数据类型多选：姓名 / 手机号 / 邮箱 / 身份证 / IP / 日期
- 生成条数：数字输入框
- 结果表格（每列一种类型）

---

## 四、典型使用场景

1. **数据库测试**：生成 UUID 作为测试数据的主键
2. **密码生成**：生成高强度随机密码
3. **Mock 接口**：生成测试用的假数据填充接口响应
4. **表单测试**：生成手机号、邮箱等测试表单验证逻辑
5. **接口压测**：批量生成随机参数用于接口测试

---

## 五、排除功能

| 功能 | 排除原因 |
|------|----------|
| UUID v1/v5/v7 | V4 已覆盖绝大多数场景 |
| 地址生成 | 数据量大，实现复杂 |
| 银行卡号 | 安全敏感，不适合插件场景 |
| JSON Schema Mock | 增加大量复杂度，后续可迭代 |
| Snowflake ID | 依赖机器标识，不适合浏览器环境 |
