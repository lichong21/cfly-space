# 颜色工具 — 功能需求文档

## 运行上下文

- **所在页面**：Options 页面（完整浏览器标签页）
- **数据存储**：`chrome.storage.local`（收藏的颜色持久化）
- **优先级**：P2（前端开发常用）

---

## 一、核心目标

提供颜色格式互转、可视化取色、对比度检查等功能，覆盖前端开发中颜色相关的常见需求。

---

## 二、功能清单

### 1. 颜色格式转换

| # | 功能 | 说明 |
|---|------|------|
| 1 | **HEX → RGB / HSL** | 输入 HEX 值（如 `#667eea`），自动转换为 RGB 和 HSL |
| 2 | **RGB → HEX / HSL** | 输入 RGB 值（如 `rgb(102, 126, 234)`），自动转换 |
| 3 | **HSL → HEX / RGB** | 输入 HSL 值（如 `hsl(228, 76%, 66%)`），自动转换 |
| 4 | **支持 Alpha 通道** | 支持 RGBA、HSLA、8 位 HEX（如 `#667eeaff`） |
| 5 | **自动识别格式** | 输入任意合法颜色值，自动识别格式并转换为所有其他格式 |
| 6 | **一键复制** | 每种格式旁提供复制按钮 |

### 2. 可视化选色

| # | 功能 | 说明 |
|---|------|------|
| 7 | **色板选色** | 提供 HSV/HSL 色板，通过拖拽选取颜色 |
| 8 | **色相条** | 色相（Hue）滑块条 |
| 9 | **透明度滑块** | Alpha 通道滑块 |
| 10 | **实时预览** | 选色过程中实时预览颜色效果和各格式数值 |

### 3. 页面取色器

| # | 功能 | 说明 |
|---|------|------|
| 11 | **EyeDropper API** | 使用浏览器原生 EyeDropper API 从屏幕任意位置取色 |
| 12 | **取色结果** | 取色后自动填入颜色值并显示所有格式 |

### 4. 对比度检查

| # | 功能 | 说明 |
|---|------|------|
| 13 | **前景/背景色** | 输入前景色和背景色 |
| 14 | **对比度计算** | 计算 WCAG 对比度比值 |
| 15 | **等级判定** | 显示 AA / AAA 等级是否通过（普通文本 / 大文本） |
| 16 | **文字预览** | 用选中的前景/背景色预览实际文字显示效果 |

### 5. 调色板收藏

| # | 功能 | 说明 |
|---|------|------|
| 17 | **收藏颜色** | 将当前颜色添加到收藏 |
| 18 | **调色板管理** | 创建多个调色板（如「项目 A 配色」「常用色」），每个调色板包含多个颜色 |
| 19 | **删除颜色** | 支持从调色板中删除颜色 |
| 20 | **点击回填** | 点击收藏的颜色，回填到转换区域 |

---

## 三、交互设计

### 布局

- 左侧：色板选色区域（色板 + 色相条 + 透明度条 + 取色按钮）
- 右上：颜色格式转换结果（HEX / RGB / HSL，每项带复制按钮）
- 右下：对比度检查区域（前景/背景色输入 + 对比度结果 + 预览）
- 底部：收藏的调色板

### 颜色输入规则

- 支持带 `#` 和不带 `#` 的 HEX 值
- 支持 3 位简写（`#fff`）和 6 位完整（`#ffffff`）
- 支持 `rgb()` / `rgba()` / `hsl()` / `hsla()` 函数格式
- 输入非法值时提示「无效的颜色值」

---

## 四、典型使用场景

1. **设计还原**：从设计稿获取 HEX 值，转换为 CSS 中使用的 RGB 或 HSL
2. **无障碍检查**：检查文字与背景色的对比度是否符合 WCAG 标准
3. **主题开发**：收藏和管理项目的品牌色、主题色
4. **页面调试**：从页面上取色获取精确的颜色值

---

## 五、排除功能

| 功能 | 排除原因 |
|------|----------|
| CSS 渐变生成器 | 增加复杂度，后续独立功能 |
| 色彩搭配建议 | 需要算法和设计理论，优先级低 |
| 图片取色 | 需要额外图片处理逻辑 |
| CMYK 格式 | 印刷色彩空间，Web 开发极少使用 |
