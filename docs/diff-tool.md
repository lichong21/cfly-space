# Diff 对比工具 — 功能需求文档

## 运行上下文

- **所在页面**：Options 页面（完整浏览器标签页）
- **数据存储**：无需持久化（纯工具型，无状态）
- **优先级**：P2（实用但实现成本较高）

---

## 一、核心目标

提供两段文本的差异对比功能，类似 VS Code 的 diff 视图，帮助程序员快速发现文本差异，适用于 code review、接口返回值比对、配置文件对比等场景。

---

## 二、功能清单

### 1. 文本对比

| # | 功能 | 说明 |
|---|------|------|
| 1 | **双栏输入** | 左侧「原始文本」，右侧「对比文本」，均为多行文本输入框 |
| 2 | **差异计算** | 基于行级别的 diff 算法，计算两段文本的增/删/改 |
| 3 | **差异高亮** | 新增行绿色背景、删除行红色背景、修改行黄色背景 |
| 4 | **行内差异** | 修改的行内部进一步高亮具体变化的字符/单词 |
| 5 | **差异统计** | 显示新增行数、删除行数、修改行数 |

### 2. 视图模式

| # | 功能 | 说明 |
|---|------|------|
| 6 | **并排视图（Side by Side）** | 左右双栏并排显示差异，默认模式 |
| 7 | **内联视图（Inline）** | 单栏显示，删除行和新增行上下排列（类似 Git diff） |
| 8 | **仅显示差异** | 折叠无差异的行，只展示有变化的区域（带上下文行数控制） |

### 3. JSON 对比模式

| # | 功能 | 说明 |
|---|------|------|
| 9 | **JSON 格式化后对比** | 自动格式化 JSON 后再对比，忽略格式差异 |
| 10 | **JSON 语义对比** | 忽略 key 顺序差异，只对比实际数据差异（可选） |

### 4. 交互操作

| # | 功能 | 说明 |
|---|------|------|
| 11 | **交换左右** | 一键交换原始文本和对比文本 |
| 12 | **清空输入** | 一键清空两侧输入 |
| 13 | **复制差异** | 复制差异结果（统一 diff 格式） |
| 14 | **差异导航** | 上一处差异 / 下一处差异快捷跳转 |
| 15 | **行号显示** | 两侧均显示行号，方便定位 |

---

## 三、交互设计

### 布局

- 顶部：工具栏（视图模式切换 + JSON 模式开关 + 操作按钮 + 差异统计）
- 主体：
  - 并排模式：左右等宽双栏，同步滚动
  - 内联模式：单栏全宽
- 双栏同步滚动：两侧滚动位置保持同步

### 大文本处理

- 使用虚拟滚动（仅渲染可视区域的行），支持大文本对比
- 超过 10000 行提示用户可能影响性能

---

## 四、典型使用场景

1. **接口调试**：对比两次接口返回值，快速找到数据变化
2. **配置对比**：对比生产环境和测试环境的配置文件差异
3. **Code Review**：粘贴修改前后的代码，查看变更内容
4. **数据核对**：对比两份 JSON 数据是否一致

---

## 五、排除功能

| 功能 | 排除原因 |
|------|----------|
| 文件拖拽上传 | 增加复杂度，复制粘贴已满足需求 |
| 语法高亮 | 增加实现复杂度，以差异对比为核心 |
| 三方对比 | 实现复杂，优先级低 |
| 目录对比 | 超出浏览器插件能力范围 |
