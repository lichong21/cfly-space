# 编码/解码工具 — 功能需求文档

## 运行上下文

- **所在页面**：Options 页面（完整浏览器标签页）
- **数据存储**：无需持久化（纯工具型，无状态）
- **优先级**：P0（程序员每日刚需，实现成本低）

---

## 一、核心目标

提供常见编码/解码格式的双向转换，覆盖 URL、Base64、HTML 实体、Unicode 四大类型，替代频繁访问在线工具网站的低效操作。

---

## 二、功能清单

### 1. URL 编码/解码

| # | 功能 | 说明 |
|---|------|------|
| 1 | **URL Encode** | 将文本中的特殊字符转换为 `%XX` 格式 |
| 2 | **URL Decode** | 将 `%XX` 格式还原为原始字符 |
| 3 | **组件编码** | 使用 `encodeURIComponent` / `decodeURIComponent` |
| 4 | **完整 URL 编码** | 使用 `encodeURI` / `decodeURI`，保留 URL 结构字符 |

### 2. Base64 编码/解码

| # | 功能 | 说明 |
|---|------|------|
| 5 | **文本 → Base64** | 将文本编码为 Base64 字符串，支持 UTF-8 |
| 6 | **Base64 → 文本** | 将 Base64 字符串解码为原始文本 |
| 7 | **文件 → Base64** | 支持选择本地文件（图片等）转换为 Base64 Data URI |
| 8 | **Base64 → 预览** | 如果 Base64 内容为图片，自动显示图片预览 |

### 3. HTML 实体编码/解码

| # | 功能 | 说明 |
|---|------|------|
| 9 | **HTML Encode** | 将 `<`, `>`, `&`, `"`, `'` 等转换为 HTML 实体 |
| 10 | **HTML Decode** | 将 HTML 实体还原为原始字符 |

### 4. Unicode 转义/反转义

| # | 功能 | 说明 |
|---|------|------|
| 11 | **Unicode 转义** | 将中文等非 ASCII 字符转换为 `\uXXXX` 格式 |
| 12 | **Unicode 反转义** | 将 `\uXXXX` 格式还原为原始字符 |

### 5. 通用交互

| # | 功能 | 说明 |
|---|------|------|
| 13 | **输入/输出双栏布局** | 左侧输入框，右侧输出框，中间操作按钮 |
| 14 | **一键复制结果** | 输出区域提供复制按钮 |
| 15 | **互换输入输出** | 点击交换按钮，将输出结果回填到输入框（方便连续转换） |
| 16 | **自动转换** | 输入内容变化后自动执行转换，无需点击按钮（可选开关） |
| 17 | **错误提示** | 解码失败时显示明确错误信息（如「非法 Base64 字符串」） |

---

## 三、交互设计

### 布局

- 顶部：编码类型切换 Tab（URL / Base64 / HTML / Unicode）
- 主体：上下双栏或左右双栏布局
  - 输入区：多行文本输入框
  - 操作区：Encode / Decode 按钮 + 交换按钮
  - 输出区：多行文本输出框 + 复制按钮
- Base64 文件模式：额外提供文件选择按钮和预览区

---

## 四、典型使用场景

1. **URL 参数调试**：将中文参数 URL Encode 后拼接到接口 URL 中
2. **接口鉴权**：将 token 或凭证进行 Base64 编码/解码
3. **前端开发**：处理 HTML 特殊字符转义，防止 XSS
4. **国际化调试**：Unicode 和中文互转，排查乱码问题
5. **图片内联**：小图片转 Base64 Data URI 用于 CSS/HTML 内联

---

## 五、排除功能

| 功能 | 排除原因 |
|------|----------|
| MD5 / SHA 哈希 | 需要加密库，后续独立模块 |
| JWT 解析 | 可用 Base64 解码中间段替代，后续迭代 |
| 文件批量转换 | 增加复杂度，单文件已满足需求 |
