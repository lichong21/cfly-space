# 时间戳转换器 — 功能需求文档

## 运行上下文

- **所在页面**：Options 页面（完整浏览器标签页）
- **数据存储**：`chrome.storage.local`，本地持久化
- **优先级**：P0（已在 PRD 中规划，高频刚需）

---

## 一、核心目标

实现 Unix 时间戳与可读日期时间的双向转换，支持秒级/毫秒级自动识别，覆盖接口调试、日志分析、跨系统数据对接等常见开发场景。

---

## 二、功能清单

### 1. 双向转换

| # | 功能 | 说明 |
|---|------|------|
| 1 | **时间戳 → 日期时间** | 输入时间戳后自动转换为可读日期时间 |
| 2 | **日期时间 → 时间戳** | 通过输入框或日期选择器输入日期，生成对应时间戳 |
| 3 | **秒/毫秒自动识别** | 根据输入位数（10 位 / 13 位）自动判断精度，无需用户手动选择 |
| 4 | **同时输出双精度** | 转换结果同时显示秒级（10 位）和毫秒级（13 位）时间戳 |
| 5 | **负数时间戳** | 支持负数时间戳，转换为 1970-01-01 之前的日期（`new Date(负数)` 原生支持，零成本） |

### 2. 输出格式

| # | 功能 | 说明 |
|---|------|------|
| 6 | **ISO 8601** | `2026-03-20T14:30:00+08:00` |
| 7 | **本地格式** | `2026-03-20 14:30:00`（默认格式） |
| 8 | **UTC 时间** | `2026-03-20 06:30:00 UTC` |
| 9 | **相对时间** | 显示距当前的相对时间描述，如「3 小时前」「2 天后」 |

### 3. 快捷操作

| # | 功能 | 说明 |
|---|------|------|
| 10 | **获取当前时间戳** | 一键获取当前时刻的秒级和毫秒级时间戳，实时刷新显示 |
| 11 | **一键复制** | 每个转换结果旁提供复制按钮，复制成功显示提示 |
| 12 | **清空输入** | 一键清空输入框和转换结果 |

### 4. 批量转换

| # | 功能 | 说明 |
|---|------|------|
| 13 | **批量模式切换** | 提供「单个 / 批量」模式切换开关 |
| 14 | **逐行转换** | 批量模式下，每行输入一个时间戳，逐行转换并展示结果 |
| 15 | **批量复制** | 一键复制所有转换结果（以换行分隔） |

### 5. 智能输入校验

| # | 功能 | 说明 |
|---|------|------|
| 16 | **位数异常提示** | 输入 9 位或 12 位数字时，提示「看起来少了一位，是否为秒级/毫秒级时间戳？」 |
| 17 | **11 位数字提示** | 输入 11 位数字时，提示「看起来多了一位，是否为秒级时间戳？」 |
| 18 | **超范围提示** | 转换结果超出合理年份范围（如 > 2100 年或 < 1900 年）时给出提示 |

### 6. 日期差值计算

| # | 功能 | 说明 |
|---|------|------|
| 19 | **双日期输入** | 提供两个日期/时间戳输入框 |
| 20 | **差值结果** | 计算并显示两个时间点之间相差的天数、小时数、分钟数、秒数 |
| 21 | **可读描述** | 显示可读的时长描述，如「1 天 2 小时 30 分钟 15 秒」 |

### 7. 秒数 → 可读时长

| # | 功能 | 说明 |
|---|------|------|
| 22 | **时长转换** | 输入秒数（如 `86400`），转换为可读时长（如「1 天」） |
| 23 | **多级展示** | 分别显示换算为天、小时、分钟的值，以及组合描述（如 `3661` → `1 小时 1 分钟 1 秒`） |
| 24 | **反向转换** | 输入天/时/分/秒组合，计算总秒数 |

### 8. 转换历史

| # | 功能 | 说明 |
|---|------|------|
| 25 | **最近记录** | 本地保留最近 10 条转换记录，展示输入值和转换结果 |
| 26 | **快速回填** | 点击历史记录可快速回填到输入框重新转换 |
| 27 | **清空历史** | 支持一键清空所有转换记录 |

## 三、交互设计

### 布局

- 顶部：输入区域（单个输入框 + 智能识别提示 + 单个/批量模式切换）
- 中部：转换结果展示区（多格式并列显示，每项带复制按钮）
- 下方左侧：日期差值计算面板（折叠式）
- 下方右侧：秒数 ↔ 可读时长转换面板（折叠式）
- 底部：当前实时时间戳显示 + 历史记录折叠面板

### 输入规则

- 输入纯数字（8-13 位，含负数）→ 识别为时间戳，自动转换为日期时间
- 输入符合日期格式的字符串 → 识别为日期时间，自动转换为时间戳
- 输入位数异常（9/11/12 位）→ 仍然转换，但显示黄色提示辅助用户判断
- 输入非法内容 → 显示错误提示「无法识别的时间格式」

## 四、差异化亮点

相比市面主流时间戳工具（epochconverter.com、unixtimestamp.com、bejson.com 等），本方案的差异化优势：

| 亮点 | 说明 |
|------|------|
| **智能单输入框** | 市面多数工具分成两个独立区域，我们用一个输入框自动识别转换方向，交互更简洁 |
| **转换历史 + 回填** | 市面工具几乎都没有历史记录功能，本地插件的天然优势 |
| **智能位数校验** | 输入 9/11/12 位时给出智能提示，市面仅 unixtimestamp.com 有类似功能 |
| **批量逐行转换** | 市面仅 epochconverter.com 支持，多数工具不支持 |
| **离线可用** | 所有在线工具都需要网络，插件天然离线可用 |

## 五、典型使用场景

1. **日志分析**：将日志中的 13 位毫秒时间戳粘贴转换，定位问题发生的具体时间
2. **批量日志排查**：从日志中复制多行时间戳，批量模式一次转换，快速建立时间线
3. **接口调试**：生成指定日期的时间戳作为接口参数
4. **数据对接**：不同系统间秒级/毫秒级时间戳互转
5. **耗时分析**：接口返回耗时秒数，转换为可读时长，如 `3661s` → `1 小时 1 分 1 秒`
6. **时间间隔计算**：计算两个时间点之间相差多久，排查任务执行时长

## 六、排除功能

| 功能 | 排除原因 |
|------|----------|
| 时区选择器 | V1.0 仅支持本地时区和 UTC，跨时区后续迭代 |
| 自定义格式模板 | 增加界面复杂度，内置格式已覆盖主要需求 |
| 右键菜单快捷转换 | 需要 Content Script，后续迭代 |
| 特殊格式转换（LDAP、GPS、.NET Ticks、HFS+ 等） | 极小众场景，不值得增加复杂度 |
| 编程语言代码示例 | 优先级低，可后续作为折叠面板迭代 |
| 微秒/纳秒精度（16 位/19 位） | JavaScript `Date` 精度限制为毫秒，支持意义不大 |
| 倒计时功能 | 与时间戳转换场景关联弱 |
