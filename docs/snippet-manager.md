# 代码片段管理（Snippet Manager）— 功能需求文档

## 运行上下文

- **所在页面**：Options 页面（完整浏览器标签页）
- **数据存储**：`chrome.storage.local`，本地持久化
- **优先级**：P2（与 Markdown 编辑器互补，专注于代码场景）

---

## 一、核心目标

提供轻量级的代码片段收藏与管理功能，支持分类、标签、语法高亮和快速复制，比 Markdown 笔记更聚焦于「保存和复用代码」的场景。

---

## 二、功能清单

### 1. 片段管理

| # | 功能 | 说明 |
|---|------|------|
| 1 | **创建片段** | 输入代码内容、标题、语言类型、描述（可选）、标签（可选） |
| 2 | **编辑片段** | 修改已保存的片段内容和元信息 |
| 3 | **删除片段** | 删除片段，二次确认防误删 |
| 4 | **收藏/置顶** | 常用片段可标记为收藏，置顶显示 |

### 2. 代码展示

| # | 功能 | 说明 |
|---|------|------|
| 5 | **语法高亮** | 根据语言类型自动语法高亮（复用已有 Prism.js 依赖） |
| 6 | **语言选择** | 支持常见语言：JavaScript、TypeScript、Python、Go、Rust、SQL、Shell、HTML、CSS、JSON、YAML 等 |
| 7 | **行号显示** | 代码区域显示行号 |
| 8 | **一键复制** | 每个片段提供复制按钮，一键复制代码内容 |

### 3. 分类与搜索

| # | 功能 | 说明 |
|---|------|------|
| 9 | **文件夹分类** | 支持创建文件夹对片段分组（如「常用函数」「SQL 模板」「Shell 脚本」） |
| 10 | **标签系统** | 每个片段可添加多个标签，支持按标签筛选 |
| 11 | **全文搜索** | 搜索框支持搜索片段标题、代码内容、描述、标签 |
| 12 | **语言筛选** | 按编程语言类型筛选片段 |

### 4. 导入导出

| # | 功能 | 说明 |
|---|------|------|
| 13 | **导出为 JSON** | 将所有片段导出为 JSON 文件备份 |
| 14 | **从 JSON 导入** | 从 JSON 文件批量导入片段 |

---

## 三、交互设计

### 布局

- 左侧：文件夹树 + 标签云
- 中部：片段列表（卡片式）
  - 每张卡片显示：标题、语言标签、代码预览（前 5 行）、标签、更新时间
  - 操作：复制 / 编辑 / 收藏 / 删除
- 右侧/弹窗：片段详情与编辑面板

### 创建/编辑面板

- 标题输入框
- 语言选择下拉框
- 代码编辑区域（多行文本框，带语法高亮）
- 描述输入框（可选，一行文字说明用途）
- 标签输入（支持多个，回车添加）
- 文件夹选择下拉框

## 四、数据模型

```typescript
interface Snippet {
  id: string
  title: string
  code: string
  language: string
  description?: string
  tags: string[]
  folderId: string
  isFavorite: boolean
  createdAt: number
  updatedAt: number
}

interface SnippetFolder {
  id: string
  name: string
  order: number
}
```

---

## 五、典型使用场景

1. **常用模板**：保存常用的代码模板（如 Vue 组件骨架、API 请求封装）
2. **SQL 片段**：收藏常用的 SQL 查询语句
3. **Shell 命令**：保存复杂的 Shell 命令和脚本片段
4. **面试准备**：整理常见算法和数据结构代码
5. **配置模板**：保存 Nginx、Docker、CI/CD 等配置模板

---

## 六、排除功能

| 功能 | 排除原因 |
|------|----------|
| 代码执行/运行 | 安全风险高，超出插件范围 |
| 版本历史 | 增加存储和实现复杂度 |
| 协作分享 | 需要服务端，与本地化原则冲突 |
| 代码补全 | 超出插件能力范围 |
| Gist 同步 | 需要 GitHub 认证，后续可迭代 |
