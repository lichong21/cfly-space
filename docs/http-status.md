# HTTP 状态码速查 — 功能需求文档

## 运行上下文

- **所在页面**：Options 页面（完整浏览器标签页）
- **数据存储**：无需持久化（静态数据，内置在代码中）
- **优先级**：P3（实现极简单，使用频率一般）

---

## 一、核心目标

提供 HTTP 状态码的快速查询参考，涵盖所有标准状态码及其含义、使用场景和常见问题排查建议，替代反复搜索文档的低效操作。

---

## 二、功能清单

### 1. 状态码查询

| # | 功能 | 说明 |
|---|------|------|
| 1 | **全量状态码列表** | 展示所有标准 HTTP 状态码（1xx ~ 5xx），按类别分组 |
| 2 | **搜索过滤** | 支持按状态码数字或关键词搜索（如输入「404」或「not found」） |
| 3 | **分类筛选** | 按类别筛选：1xx 信息、2xx 成功、3xx 重定向、4xx 客户端错误、5xx 服务端错误 |

### 2. 状态码详情

| # | 功能 | 说明 |
|---|------|------|
| 4 | **状态码名称** | 如 `200 OK`、`404 Not Found` |
| 5 | **含义说明** | 简明扼要的中文解释 |
| 6 | **使用场景** | 该状态码的典型使用场景描述 |
| 7 | **常见原因** | 遇到该状态码时的常见原因（尤其是 4xx/5xx） |
| 8 | **排查建议** | 针对错误类状态码，给出排查方向建议 |

### 3. 分类颜色标识

| 类别 | 颜色 | 说明 |
|------|------|------|
| 1xx | 蓝色 | 信息性响应 |
| 2xx | 绿色 | 成功响应 |
| 3xx | 橙色 | 重定向 |
| 4xx | 红色 | 客户端错误 |
| 5xx | 紫色 | 服务端错误 |

## 三、内置状态码清单

### 常用状态码（必须包含）

| 状态码 | 名称 | 简要说明 |
|--------|------|----------|
| 200 | OK | 请求成功 |
| 201 | Created | 资源创建成功 |
| 204 | No Content | 成功但无返回内容 |
| 301 | Moved Permanently | 永久重定向 |
| 302 | Found | 临时重定向 |
| 304 | Not Modified | 资源未修改，使用缓存 |
| 400 | Bad Request | 请求参数错误 |
| 401 | Unauthorized | 未认证 |
| 403 | Forbidden | 无权限 |
| 404 | Not Found | 资源不存在 |
| 405 | Method Not Allowed | HTTP 方法不支持 |
| 408 | Request Timeout | 请求超时 |
| 409 | Conflict | 资源冲突 |
| 413 | Payload Too Large | 请求体过大 |
| 415 | Unsupported Media Type | 不支持的媒体类型 |
| 422 | Unprocessable Entity | 语义错误 |
| 429 | Too Many Requests | 请求频率超限 |
| 500 | Internal Server Error | 服务器内部错误 |
| 502 | Bad Gateway | 网关错误 |
| 503 | Service Unavailable | 服务不可用 |
| 504 | Gateway Timeout | 网关超时 |

## 四、交互设计

### 布局

- 顶部：搜索框 + 分类筛选按钮（All / 1xx / 2xx / 3xx / 4xx / 5xx）
- 主体：状态码卡片列表
  - 每张卡片：状态码（大字号）+ 名称 + 简要说明
  - 点击卡片展开详情（含使用场景、常见原因、排查建议）
- 卡片带对应类别的颜色边框/标签

### 交互细节

- 搜索实时过滤，无需回车
- 默认展示全部，点击分类按钮切换
- 卡片可折叠/展开

---

## 五、典型使用场景

1. **接口调试**：收到非预期状态码时，快速查阅含义和排查建议
2. **API 设计**：开发 REST API 时，查阅正确的状态码使用规范
3. **日常查阅**：记不清某个状态码含义时快速查阅

---

## 六、排除功能

| 功能 | 排除原因 |
|------|----------|
| 自定义状态码 | 非标准状态码场景极少 |
| 多语言切换 | 中文版已覆盖目标用户 |
| 状态码对比 | 实用性低 |
