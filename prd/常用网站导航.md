## 二、需求背景

日常办公和开发过程中，用户经常需要访问一组固定的网站（如内部系统、文档平台、工具站点等）。目前用户依赖浏览器书签栏或手动输入地址，存在以下痛点：

1. **书签过多**：浏览器书签数量庞大，常用网站淹没在大量书签中，查找效率低。
2. **跨浏览器不同步**：更换浏览器或设备后书签需重新整理。
3. **缺少分类管理**：浏览器书签的分类能力有限，无法按业务场景灵活分组。
4. **入口分散**：常用网站分散在不同书签文件夹中，无法一目了然。

为解决上述问题，在 CFly Space 侧边栏新增「常用网站」导航模块，提供轻量化的常用网站管理和快速访问能力。

## 三、功能范围

### 模块定位

在 Options 页面侧边栏（`sidebar-nav`）中新增「常用网站」导航项，点击后在主内容区展示网站导航面板，用户可以添加、编辑、删除和快速打开常用网站。

### 与现有模块的关系

| 现有模块     | 关系     |
| ------------ | -------- |
| JSON 格式化  | 并列模块 |
| 时间戳转换   | 并列模块 |
| 喝水提醒     | 并列模块 |

常用网站导航作为侧边栏中独立的导航分区（「快捷入口」），与现有「工具箱」分区并列。

## 四、详细功能需求

### （一）侧边栏入口

1. 在侧边栏现有「工具箱」导航分区下方，新增「快捷入口」导航分区。
2. 该分区下添加「常用网站」导航项，图标使用 `🌐` 或类似的地球图标。
3. 点击后切换主内容区为常用网站导航面板。

### （二）网站导航面板

#### 1. 网站卡片展示

- 以卡片网格形式展示用户添加的常用网站，每行 3-4 个卡片（响应式布局）。
- 每张卡片展示以下信息：
  - **网站图标**（Favicon）：自动从网站 URL 获取，获取失败时显示网站名称首字。
  - **网站名称**：用户自定义，限制 20 字符以内。
  - **网站地址**：展示简短域名，悬浮时 tooltip 显示完整 URL。
- 点击卡片在新标签页中打开对应网站。

#### 2. 网站分组功能

- 支持按分组管理网站，默认提供「未分组」分组。
- 用户可创建自定义分组（如「开发工具」「内部系统」「文档资料」等）。
- 每个分组可折叠/展开，折叠状态持久化存储。
- 分组名称限制 10 字符以内。

#### 3. 添加网站

- 导航面板顶部提供「添加网站」按钮。
- 点击后弹出表单弹窗，包含以下字段：
  - **网站名称**（必填）：文本输入，最多 20 字符。
  - **网站地址**（必填）：URL 输入，需校验 URL 格式合法性（支持 http/https 协议）。
  - **所属分组**（可选）：下拉选择，默认为「未分组」，支持新建分组。
- 提交后网站卡片实时出现在对应分组中。

#### 4. 编辑与删除

- 每张网站卡片右上角提供操作菜单（hover 时显示），支持：
  - **编辑**：弹出编辑弹窗，可修改名称、地址、分组。
  - **删除**：二次确认后删除该网站。
- 分组标题区域提供操作菜单，支持：
  - **重命名分组**：修改分组名称。
  - **删除分组**：删除分组时，组内网站移至「未分组」。

#### 5. 拖拽排序（V1.1 可选）

- 支持卡片在组内拖拽调整顺序。
- 支持卡片跨分组拖拽移动。

### （三）数据存储

- 网站数据存储在 `chrome.storage.local`，与现有模块保持一致。
- 存储结构设计：

```typescript
interface QuickSite {
  id: string;           // 唯一标识（UUID）
  name: string;         // 网站名称
  url: string;          // 网站地址
  groupId: string;      // 所属分组 ID
  order: number;        // 排序序号
  createdAt: number;    // 创建时间戳
}

interface SiteGroup {
  id: string;           // 分组 ID
  name: string;         // 分组名称
  order: number;        // 分组排序序号
  collapsed: boolean;   // 是否折叠
}

interface QuickSiteState {
  sites: QuickSite[];
  groups: SiteGroup[];
}
```

- 存储键名：`quickSites`。
- 数据变更后实时同步至 `chrome.storage.local`。

### （四）Favicon 获取策略

- 优先使用 Google Favicon Service：`https://www.google.com/s2/favicons?domain={domain}&sz=32`。
- 备选方案：使用目标网站 `/favicon.ico` 路径。
- 加载失败时，取网站名称首字符作为图标，背景色根据名称生成固定的渐变色。

## 五、交互与视觉规范

### 视觉风格

- 与现有模块保持一致，主色调 `#667eea` / `#764ba2`（渐变色）。
- 卡片背景色 `#ffffff`，hover 时添加阴影效果。
- 卡片圆角 `8px`，间距 `12px`。

### 空状态

- 用户未添加任何网站时，展示空状态引导：居中显示引导图标和文案「还没有添加常用网站，点击上方按钮添加吧」。

### 操作反馈

- 添加/编辑成功后，显示轻量 toast 提示「添加成功」/「修改成功」。
- 删除操作需二次确认弹窗。

## 六、权限说明

本模块无需新增浏览器扩展权限，复用现有 `storage` 权限即可。Favicon 获取通过 `<img>` 标签加载，不需要额外网络权限。

## 八、验收标准

1. 侧边栏「快捷入口」分区正常展示，点击「常用网站」可切换至导航面板。
2. 可正常添加、编辑、删除网站，表单校验正确。
3. 网站卡片点击可在新标签页中打开对应网站。
4. 分组功能正常：创建、重命名、删除分组，折叠/展开状态正确持久化。
5. Favicon 正确展示，加载失败时展示名称首字符。
6. 数据持久化正常，刷新页面后数据不丢失。
7. `pnpm compile` 类型检查通过，无类型错误。
